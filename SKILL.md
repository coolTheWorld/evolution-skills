A question arrives pre-framed, and the framing is usually the weakest part of it. Hold the answer: **steelman** both sides, isolate the **crux**, and rule only once the crux is settled.

## 1. Restate the real problem

Say back what the user is actually trying to solve, in a stronger and more complete form than they stated it — the version they would have written with more time.

Separate the stated ask from the underlying goal. Name the constraints they are treating as fixed, and what outcome would count as solved.

Done when the restatement names the goal, the fixed constraints, and the win condition, and is one the user would sign.

## 2. Steelman both sides

Build the strongest case **for** the user's current position, then the strongest case **against** it. Where they hold no position yet, steelman the two strongest live options instead.

Argue each side as its best advocate would — from its best evidence, granting it its most favourable reading. A case the opposing advocate would call unfair is a strawman wearing the label.

Look up whatever can be settled by fact — files, tools, the web — and argue from what you find rather than from what sounds plausible.

Done when each case rests on premises the other side concedes, and neither was easy to write.

## 3. Isolate the crux

The **crux** is where the two cases actually part company: the variable whose value, flipped, flips the verdict. Surface disagreement usually is not the crux — both sides often share the facts and diverge on one weighting, one probability, one constraint.

State where the cases genuinely diverge, then rank the crux variables by how far the conclusion moves with each.

Done when each crux reads as a conditional you can check: *if it is X, the answer is A; if it is Y, the answer is B.*

## 4. Ask the crux question

Ask the single question whose answer moves the verdict most. Ask exactly one, then stop and wait for the answer.

Carry your own recommended answer with the question, so the user is correcting a position rather than filling a blank.

Reserve the question for what needs the user's judgement, private context, or risk appetite; anything you can look up, look up.

## 5. Settle the crux, then rule

When the answer lands, check it against the crux: does it now determine the verdict?

**Still open** — return to step 4 with the next crux question. The verdict stays held.

**Determined** — deliver, in this order:

- **Verdict** — one committal sentence: back the position, kill it, or name the modified version that survives.
- **Why** — the case that survived, and the specific thing that killed the other one.
- **Next actions** — ordered and concrete, each one startable today.

Done when the verdict names a course of action and cites the crux value that decided it.
